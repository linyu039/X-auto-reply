模型接口

兼容 DeepSeek / OpenAI / 月之暗面 / 通义 / 本地 vLLM 等一切 /chat/completions 接口。

DeepSeek 的多模态模型是 deepseek-flash（V4.1 Flash），和 deepseek-chat 同一个 base_url、同一个 key，只换模型名。留空则带图时仍用上面的模型名。用 OpenAI 就填 gpt-4o，通义填 qwen-vl-max，智谱填 glm-4v。图片格式按 OpenAI 的 image_url 发，主流服务商都认；对方不吃图会自动退回纯文字，不会报错。

回复策略
风格预设

选中后下面的人设/规则/长度/温度会被整段替换，点「保存配置」才生效。想改哪句直接改了保存，预设只是起点。

跟随模式

默认关掉自动发送：点开回复 → 插件填好 → 停住 → 你自己按「回复」。想回下一条，再手动点开另一条。

默认开启：面板上点一次「开始连续」，会一条接一条往下回，回完「本次上限」条自动停。想一条一条手动控制，把这个勾去掉。

点赞

点赞是通知对方的，比回复更容易被看到。跟着回复点，一条推文一个赞，不会刷屏。已经赞过的自动跳过。

回关（评论完关注对方）

已经是关注状态的人直接跳过，不会重复点。X 对关注频次有硬限制，撞到限制时插件不会停，只是暂停关注，回复照常继续，等冷却时间过去自动接着关注。单个账号一天安全关注量大概 100–200，别把上限拉满。
